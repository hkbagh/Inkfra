# AWS Starter Network

A compact AWS baseline with a VPC, public subnet, internet gateway, security group, EC2 instance, and S3 bucket.

Generated by [Inkfra](https://github.com/hkbagh/Inkfra).

## Resources

- `aws_vpc.main_vpc` (Main VPC)
- `aws_subnet.public_subnet` (Public Subnet)
- `aws_internet_gateway.internet_gateway` (Internet Gateway)
- `aws_security_group.web_security_group` (Web Security Group)
- `aws_instance.web_server` (Web Server)
- `aws_s3_bucket.assets_bucket` (Assets Bucket)

## Usage

```bash
terraform init
terraform fmt -check
terraform validate
terraform plan
terraform apply
```
