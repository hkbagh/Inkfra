# AWS Serverless Edge API

Global edge and event-driven serverless stack with CloudFront CDN, encrypted private S3 origin, Cognito auth, API Gateway, Lambda, DynamoDB, FIFO SQS queue, SNS alerts, S3 remote state, and GitHub Actions OIDC.

Generated by [Inkfra](https://github.com/hkbagh/Inkfra).

## Resources

- `aws_cloudfront_distribution.cloudfront_edge_cdn` (CloudFront Edge CDN)
- `aws_s3_bucket.static_web_origin` (Static Web Origin)
- `aws_api_gateway_rest_api.edge_rest_api` (Edge REST API)
- `aws_cognito_user_pool.cognito_users` (Cognito Users)
- `aws_lambda_function.api_handler_lambda` (API Handler Lambda)
- `aws_dynamodb_table.sessions_dynamodb` (Sessions DynamoDB)
- `aws_sqs_queue.async_jobs_fifo` (Async Jobs FIFO)
- `aws_sns_topic.ops_alerts_topic` (Ops Alerts Topic)

## Usage

```bash
terraform init
terraform fmt -check
terraform validate
terraform plan
terraform apply
```
