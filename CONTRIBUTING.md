# Contributing

Thanks for contributing to Inkfra!

## Development setup

```bash
npm install
npm run dev
```

## Before submitting

- Run `npm run lint`
- Run `npm run build`
- Run `npm run test`
- Update documentation for user-facing changes.

## Pull requests

- Keep changes focused and well-described.
- Include tests for new logic where possible.
- Follow existing code style.
