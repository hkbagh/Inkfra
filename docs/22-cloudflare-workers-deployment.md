# Deploy to Cloudflare Workers

Inkfra is deployed as a Cloudflare Worker that serves the static Vite build through the `ASSETS` binding.

## Architecture

- `src/worker.ts` forwards requests to `env.ASSETS`.
- `wrangler.toml` points the assets binding at `./dist` and enables SPA fallback.
- The build output is generated by `npm run build`; `wrangler.toml` does not run a custom build.

## Local development

```bash
npm run build
npm run cf:dev
```

## Deploy manually

```bash
npm run cf:deploy
```

This runs `npm run build` and then `wrangler deploy`.

To deploy without rebuilding:

```bash
npx wrangler deploy
```

Only do this when `dist/` is known to be current.

## CI/CD

Choose one deployment path:

### Option A: Cloudflare Workers Builds

Cloudflare builds and deploys on push to `main`. Configure the build command, deploy command, and build token in the dashboard. See [Cloudflare Dashboard CI/CD](./23-cloudflare-dashboard-cicd.md).

### Option B: GitHub Actions

Workflow: `.github/workflows/deploy-cloudflare.yml`

Required repository secrets:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

The workflow validates the token and account before deploying, then uploads Wrangler logs as an artifact.

## Open-source notes

- No secrets are committed.
- `wrangler.toml` is committed.
- `dist/` and `.wrangler/` are gitignored.
- Builds use Node 24 and npm 11.6.2, pinned in `.node-version` and `package.json`.
